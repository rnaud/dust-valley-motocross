# AI artwork

Generated with the OpenAI Images API (`gpt-image-1.5` for the menu hero; `gpt-image-1-mini` for textures) and optimized to WebP locally. API keys live outside the repository; no key is committed.

## Assets

- `src/assets/menu-hero.webp` — 1990s extreme-sports poster: rider launching toward the camera, redrock canyon, sunset flare, acid-lime accents. No text or logos.
- `src/assets/rock.webp` — seamless layered red sandstone albedo used on buttes and boulders.
- `src/assets/ground-detail.webp` — grayscale dry sand/gravel detail, used in the terrain shader.
- `src/assets/ui-panel.webp` — dark brushed-metal/checker panel texture used behind menus and settings.

## Prompts (short form)
